Code Library

Annotated, general-use templates in Stata, R, and Python. Every module uses the same dataset so you can download it once and run any template. Each module also includes a plain-language intuition file and a full mathematical derivation.

Dataset — CES 2020 Common Content
Download the CSV (~188 MB) from Harvard Dataverse and save it as CES20_Common_Content_validated.csv in your working directory. Run Module 01 first; it cleans and saves CES2020_clean.parquet, which all other modules read.

doi.org/10.7910/DVN/E9N6PH  ·  Codebook

Schaffner, B., Ansolabehere, S., & Luks, S. (2021). Cooperative Election Study Common Content, 2020. Harvard Dataverse.
